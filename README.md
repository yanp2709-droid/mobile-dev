# flutter_application_yan

A new Flutter project.

## Firebase setup

This app now includes Firebase email/password authentication.

To finish setup for this project, run:

```bash
flutterfire configure --platforms=android,ios,macos,web,windows
```

Then enable `Email/Password` in the Firebase Authentication console and restart the app.
